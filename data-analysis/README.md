# Data-analysis modules

This folder preserves the original submitted course notebooks from modules M24–M33. They are educational snapshots, not guaranteed to run outside their original environment.

- [Portable notebook copies](portable/) — M24, M26, M27 and M29 with adapted file locations.
- [Video-game sales EDA](video-game-eda/) — original figures, saved CSV summaries and a portable M33 notebook.
- [Source data manifest](source-data-status.md) — outstanding dependencies and validation tasks.

All original notebooks have saved execution outputs removed to keep the source snapshots readable. For modules with original macOS absolute paths, start with the portable edition or consult the data manifest.
